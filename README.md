# Dave Lima — portfolio

Personal site for Dave Emanuel G. Lima. Next.js, React, TypeScript, and Tailwind.

## Scripts

- `npm run dev` — local dev server
- `npm run lint`
- `npm run build`

## Resume and machine-readable files

- `public/Dave_Lima_Resume.pdf` — downloaded by the resume handoff on the home page. The path is `contact.resumePdfPath` in `src/lib/portfolio-data.ts`.
- `public/resume.json` — JSON Resume export. Update it when the portfolio data changes.
- `public/llms.txt` — plain-text context for language models. Linked from the footer.
